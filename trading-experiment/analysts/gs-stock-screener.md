## Detail on this run's flags

**The AMD/INTC/ARM batch is the most consequential data-quality finding of the day.** Three large, liquid, heavily-covered names returned simultaneous, large, implausible intraday moves (+8%, +5%, +12%) with no supporting headline, no cross-confirmation from any held-name read, and no consistency with their own last-trusted carryforward levels. Paired with this morning's NVDA miss ($219.74 vs. $236.3477, same date), that's now two separate incidents in one day of this tool returning a wrong-but-plausible-looking number for a mega/large-cap, not an obscure illiquid name. This desk is no longer treating WebSearch equity quotes as presumptively correct for *any* ticker without a second source — the presumption has flipped.

**The ALAB forward-dated result is a new failure mode worth naming separately from staleness.** Every prior data-quality flag this desk has logged (MU/AVGO/SNDK caching, OMCL/GEHC stale prices, the shutdown's 2025-dated recirculation) has been a *backward*-dated problem — old information presented as current. Today's ALAB hit and the market-close snippet in flag #6 are the first *forward*-dated examples this desk has caught — information that, if real, hasn't happened yet. Rule 4's dateline-check discipline should explicitly cover both directions going forward.

**MRVL's Investor Day remains the sheet's best catalyst, and the clock is now inside 24 hours.** Fresh, corroborating (not contradicting) Street detail this run — Oppenheimer's $325 target raise, Needham/Rosenblatt's $300 floor, the ~70x trailing multiple context — sharpens the case this desk has made for three straight reports: this is worth a pre-event cross-vet, not a reactive post-event one.
