## 1. GE HealthCare (GEHC) — full rebuild, mandatory post-close-and-hold refresh

### Why this run rebuilds instead of rolling
BR's 9/17 upside watch line ($65, close-and-hold design) fired for the first time on 9/22's official close of $66.27, after seven straight intraday-only touches the day before. Per that line's own written design (mirroring the OMCL/GEHC revisit-line pattern), a close-and-hold is a **mandatory MS DCF refresh trigger**, not a buy signal. GS's 9/23 report named this desk directly as the one that hasn't caught up yet. This section is that catch-up.

### Fresh diligence this run (WebSearch)
- **Q2 2026 (last reported quarter):** revenue $5.3B, +3.5% organic YoY; adjusted EPS $1.13, +6.6% YoY; adjusted EBIT $750M, 14.2% margin (-40bps YoY on mix/tariff headwinds); organic orders +11.1% YoY, the highest since the 2023 spin-off; book-to-bill 1.15x; backlog a record $23.9B (+$2.6B YoY, +$2.1B sequentially). **FY2026 guidance maintained**: 3-4% organic sales growth, 10-40bps adjusted EBIT margin expansion, $4.80-$5.00 adjusted EPS.
- **Sofie Biosciences (~$1B radiopharma target):** still unconfirmed as of this run — FT/Reuters reporting "advanced negotiations," a deal "could be announced as soon as next week," neither company has commented on the record. No financing structure, no closing date. **Held out of the base case**, same treatment as every prior report — a real but unpriced upside optionality, not a downside risk (a debt-financed deal would be the main way this bites the net-debt assumption below).
- **Dividend:** +14.3% raise ($0.035→$0.04/qtr, first raise in 7 quarters), announced 9/22, ex-div 10/23. A genuine management-confidence signal but immaterial to enterprise value (yield still <0.3%) — logged, not modeled.
- **Board appointment (Pascal Desroches, eff. 1/4/27):** governance-only, no valuation impact.
- No guidance cut, no backlog reversal, no CFO-transition credibility discontinuity — the three disqualifiers in this book's own GEHC structural-break framework (state.md rule 2) all remain clean.

### 5-year revenue projection
Base FY2025 revenue ≈ $19.7B. Growth ramps toward the top of FY26 guidance as the record backlog converts, then normalizes toward GEHC's historical mid-single-digit trend:

FY2026E sits at the low-to-mid end of management's own 3-4% guide (conservative given H1 tracked at 3.5%); FY2027 ticks up on backlog conversion (11.1% orders growth outrunning revenue growth by a wide margin is exactly the kind of gap that shows up in the following year), then fades back to trend.

### WACC
**8.5%**, unchanged since the 9/10 rebuild. 10-year Treasury ~4.93% as of 9/22's close (fresh WebSearch, consistent with state.md's own 9/23 read) — comfortably below the 5%-held-a-full-week WACC-rebuild criterion (rule 11's addendum), so no rate-driven rebuild is warranted this run regardless of the price-driven trigger. Cost of equity assumes a moderate beta (~1.0-1.1, defensive healthcare-equipment profile) over a ~6% ERP; cost of debt reflects GEHC's investment-grade, moderate-leverage profile (~$8.0B net debt, BW's 8/20 10-Q-sourced figure, not re-verified this run).

### Terminal value & enterprise value (base case: WACC 8.5%, g 3.0%)
Terminal FCF = FY2030E $2.59B × 1.03 = $2.67B → TV = $2.67B / (8.5%-3.0%) = $48.5B, discounted at 8.5% over 5 years (factor 0.665) = **$32.3B**. PV of explicit FY26-30 FCFs = **$8.9B**. Enterprise value = **$41.1B**. Less net debt ~$8.0B → equity value ≈ **$33.1B**. ÷ ~468M shares outstanding → **fair value ≈ $70.8/share**.

### DCF value vs. current market price
Fair value $70.8 vs. live price $66.18 (state.md, 9/23 ~09:37 ET) → gap = (70.8 − 66.18) / 66.18 = **+6.98% undervalued**. Essentially unchanged from the 9/10 rebuild's +6.8-10.9% range depending on the day's price — this run's price ($66.18) is almost exactly where GEHC traded most of last week, so the gap lands in the middle of that range, not at either extreme.

### Verdict: **UNDERVALUED, gap ≈ +7.0% — model reaffirmed, not a green light**
No trim, no add. This satisfies BR's mandatory post-close-and-hold refresh (rule/trigger discharged, logged for the team). GEHC is already at/above BR's ~4% target satellite weight (~4.78% of pool per BW's 9/22 read) — an add still needs an explicit overweight case from BR, which no desk has made. The Needham $93 target (still the highest published target on the name, well above this desk's own $70.8) remains a sell-side multiple-based call, not new disclosed cash-flow data, and this desk's bottom-up build continues to be the one that should govern sizing.

### Key assumptions that could break the model
- **Sofie Biosciences**, if it closes on debt-heavy terms, adds to net debt and would need explicit re-modeling (not currently priced); if all-cash from balance-sheet capacity with no revenue/EPS accretion disclosed, minimal EV impact either way until synergies are guided.
- **Backlog-to-revenue conversion timing**: FY2027's growth bump assumes the record 11.1% orders growth actually shows up in shipped/recognized revenue on a normal lag; a conversion delay (supply chain, install-base capacity) would push the FY2027 step-up out a year, compressing near-term FCF and the base case toward the ~$66-68 range.
- **Margin recovery**: the FY26 guide explicitly leans on H2 margin improvement (tariff/mix headwinds easing) — if that doesn't materialize, the 14.6%→16.3% margin glide path this model assumes is too aggressive, and fair value compresses toward the WACC 9%/g 2.5% cell (~$58).
- **PCS (Patient Care Solutions) segment**: the "strategic review" disclosed at the Q2 print (still open, no update this run) could mean a divestiture (a clean, accretive outcome not modeled) or a drawn-out distraction (a mild negative not modeled either) — genuinely two-sided, watched but not yet in the numbers.
- As always: net debt (~$8.0B) is BW's 8/20 10-Q figure, not independently re-pulled this run.
